# About

Aplicación web para la gestión de usuarios y reservas de habitaciones, con dashboard administrativo, control de disponibilidad por fechas y persistencia de datos.

### Funcionalidades principales

- Dashboard administrativo con métricas de reservas.
- Gestión de habitaciones y reservas.
- Validación de solapamiento de reservas por fecha.
- Separación de roles (administrador / usuario).
- Manejo de estados y notificaciones en interfaz.

## Nota

El proyecto utiliza una API mock externa para la persistencia de datos. 
Actualmente los endpoints pueden no estar disponibles, pero la lógica de integración y manejo de datos está implementada correctamente.

### Limitaciones actuales

- Uso de API mock para simulación de persistencia.
- Falta de backend propio y base de datos real.
- Interfaz básica enfocada en funcionalidad.

### Posibles extensiones

- Reemplazo de API mock por backend propio.
- Persistencia real con base de datos.
- Mejora en validaciones y manejo de errores.
